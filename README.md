# tech-blog-brief

一个将技术知识点转化为**简明技术短文**的 AI Agent Skill。

输入一个知识点（TCP 三次握手、动态规划解题步骤……），输出一篇**直给、准确、有钩子**的 Markdown 博客文章。800-1500 字，不讲废话，不注水。

## ✨ 功能特性

- 🎯 **直给型文风**：首句即具体事物，无"众所周知"式废话，有废话/直给对照示例
- 🧭 **知识类型适配**：协议机制 / 算法解题 / 概念解释 / 对比辨析，四种逐节写作模板
- ⚖️ **准确性纪律**：不捏造数字、术语先定义、每步讲"为什么"
- 📐 **字数硬约束**：单篇 800-1500 字，超长自动砍，过短自动补
- 🧪 **验证清单**：写完逐项自查标题/术语/边界/风格/字数

## 📋 依赖

| 依赖 | 说明 |
|------|------|
| 支持 SKILL.md 的 AI Agent | Trae / GitHub Copilot / Claude Code 等 |

## 🚀 安装

### Trae

```bash
cp -r tech-blog-brief/ ~/.trae/skills/
```

### GitHub Copilot

```bash
cp -r tech-blog-brief/ ~/.copilot/skills/
```

## 💬 使用

直接在对话中说：

```
写一篇关于 TCP 三次握手的博客

把动态规划的解题步骤写成一篇文章

用 tech-blog-brief 写一篇 REST vs gRPC 的对比
```

输出：一个 `.md` 文件（如 `TCP三次握手.md`），`computer://` 链接交付。

## 📁 目录结构

```
tech-blog-brief/
├── SKILL.md                         # 核心指令（800-1500 字硬约束 + voice 标准）
├── README.md                        # 本文件
├── LICENSE                          # MIT License
├── references/
│   └── writing-patterns.md          # 4 种知识类型逐节写作模板
└── examples/
    └── tcp三次握手.md                # 示例输出（protocol 类型）
```

## 🛠️ 写作流程

```
知识点输入 → 判定知识类型(4选1) → 打开写作模板 → 按模板写作
    → 按 voice 标准自查 → 字数校验 → 输出 .md 交付
```

## ✍️ 知识类型与模板

| 类型 | 适用 | 核心结构 |
|------|------|---------|
| protocol | 协议 / 机制 / 流程 | 类比开场 → 逐步拆解 → 为什么这样设计 → 边界 |
| algorithm | 算法 / 解题方法 | 问题特征 → 通用步骤模板 → 例题走一遍 → 易错点 |
| concept | 概念解释 | 一句话定性 → 拆解组成 → 为什么需要 → 反直觉点 |
| compare | 对比辨析 | 差异表 → 逐维度详解 → 本质区别 → 怎么选 |

## ⚠️ 已知限制

- 单篇上限 1500 字——深度源码分析不在本 Skill 范围
- 精确量化数据需用户提供来源，Skill 不凭空捏造
